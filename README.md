# FUNCH
## QA Engineer Assingnment

## โจทย์
จัดทำ Test Case - Scenario ตาม UI ที่อยู่ใน folder UI-example

##### ข้อกำหนด
- Test Cases - Test Scenarios จะต้องครอบคลุมมากที่สุดเท่าที่จะเป็นไปได้ โดยจะสร้างเป็นเอกสาร หรือ สามารถใช้โปรแกรม project management tool ใดก็ได้ 
- เอกสารจะอยู่ในรูปแบบใดก็ได้ที่ตัว candidate คิดว่าเหมาะสม
- สามารถกำหนดรูปแบบของเอกสารได้เอง เช่น ควรประกอบไปด้วยข้อมูลใดบ้าง และจัดวาง layout ยังไง ให้ง่ายต่อการทำงานร่วมกับทีมอื่นๆให้มากที่สุด
- สามารถมีข้อเสนอแนะเพิ่มเติม หรือแสดงความคิดเห็นได้อย่างอิสระในเรื่องของ UI เว็บไซต์ตัวอย่าง

## เกณฑ์การให้คะแนน
1. รายละเอียดของ TestCase ว่าเหมาะสม และ ถูกต้องครบถ้วน
2. รูปแบบของเอกสารที่จัดทำ มีความถูกต้อง ครบถ้วน และเข้าใจง่าน
